# Учёт продаж (Страйкбол / Охота)

Локальное веб-приложение для управления складом, заказами и учётом прибыли. 
Написано на Python (FastAPI + SQLite) в одном файле `app.py`. Работает локально, данные хранятся в файле `shop.db`.

## Стек
* **Python 3.10+**
* **FastAPI** (бэкенд)
* **SQLite** (база данных, без установки сервера)
* **Jinja2** (HTML-шаблоны встроены в код)
* **Chart.js** (графики на странице отчётов)

## Возможности

**Склад**
* Карточки товаров с фото, ценой продажи и категориями.
* Партионный учёт (FIFO). Цена закупки зависит от партии.
* Сверка склада: автоматический расчёт остатков по формуле «Закуплено − Продано − Брак».

**Заказы**
* Учёт источника клиента (Авито, Telegram, ВК, Звонок).
* Автоподстановка цены при добавлении товара.
* Гибкая система скидок.
* Контроль статусов (Вручён, Возвращён) с автоматическим возвратом товара на склад.

**Отчёты**
* Графики прибыли и выручки по дням.
* Разделение продаж по источникам.
* Рейтинг товаров по марже.
* Экспорт отчёта в печать (через Ctrl+P) с чистым ГОСТ-форматом.
